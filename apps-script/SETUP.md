# חיבור הטופס לגיליון Google (5 דקות, פעם אחת)

עד שמחברים גיליון, האתר שולח כל אישור הגעה אליכם בוואטסאפ. אחרי החיבור הכול נכנס לטבלה אחת עם סיכום אוטומטי.

1. פותחים גיליון חדש: <https://sheets.new> ונותנים לו שם, למשל "אישורי הגעה – תום ומיה".
2. בתפריט: **תוספים ← Apps Script** (Extensions → Apps Script).
3. מוחקים את מה שכתוב שם, ומדביקים את כל התוכן של הקובץ [`Code.gs`](Code.gs). שומרים (Ctrl+S).
4. למעלה מימין: **Deploy ← New deployment**.
   - Select type (גלגל השיניים) ← **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - לוחצים **Deploy**, ומאשרים את ההרשאות (Authorize access ← בוחרים את החשבון ← Advanced ← Go to project ← Allow).
5. מעתיקים את ה‑**Web app URL** (מתחיל ב‑`https://script.google.com/macros/s/` ונגמר ב‑`/exec`).
6. מדביקים אותו ב‑[`js/config.js`](../js/config.js) בשדה `rsvpEndpoint`, או פשוט שולחים את הכתובת ל‑Claude והוא יעדכן, יפרסם ויריץ בדיקה מול הגיליון האמיתי.

## מה מקבלים בגיליון

- גיליון **RSVP**: שורה לכל משפחה – שם, מגיעים (כן/לא), בוגרים, ילדים, אלרגיות, ברכה, שפה, מתי נרשמו ומתי עדכנו.
- גיליון **סיכום**: סה״כ בוגרים, ילדים, סה״כ מגיעים, כמה משפחות אישרו וכמה לא. מתעדכן לבד, גם אם מוחקים או מתקנים שורות ידנית.
- מי שממלא שוב עם אותו שם ושם משפחה – השורה שלו מתעדכנת ולא נוצרת כפילות. (אם מישהו כתב את השם אחרת בפעם השנייה תיווצר שורה נוספת; פשוט מוחקים את הישנה.)
- כדי לשתף עם הדר: כפתור **Share** בגיליון.

## אם משנים את `Code.gs` בעתיד

Deploy ← **Manage deployments** ← עיפרון ← Version: **New version** ← Deploy. הכתובת נשארת אותה כתובת.
